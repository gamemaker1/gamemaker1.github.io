# Website

> [gamemaker1.github.io](https://gamemaker1.github.io)

My personal site, built with [Astro](https://astro.build) and
[Bun](https://bun.sh). Content is markdown with frontmatter, styling is
Tailwind compiled at build time, and the output is static HTML with no
client-side JavaScript beyond the theme toggle.

---

<sub>
Parts of the codebase (such as the CSS) have been written with the help
of generative AI (Claude Opus 5). The content is all written by me!
</sub>
